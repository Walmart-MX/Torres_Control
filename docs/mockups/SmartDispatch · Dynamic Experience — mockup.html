Misma interfaz, siete atmósferas

Estructura, textos y jerarquía idénticos en las siete. Solo cambian el acento, el velo de fondo, los ornamentos del encabezado y los elementos ambientales.

Cómo se estructura el Theme Engine

Un tema es un archivo de datos, no de código de interfaz. El motor lo resuelve por fecha, mezcla los tokens y monta los elementos ambientales. Agregar theme-navidad es crear un archivo y sumar una línea al registro; el resto de la aplicación no se modifica.

Estructura de archivos

src/theme-engine/
  theme-engine.js     resolver por fecha + aplicador
  theme-registry.js   una línea por tema
  themes/
    default.js
    halloween.js
    dia-de-muertos.js
    navidad.js
    san-valentin.js   ...
  ambient/
    particles.js      petalos, copos, chispas, motas
    strips.js         banderines, papel picado, luces
  theme-engine.css    solo consume variables --t-*

Contrato de un tema

export default {
  id: 'dia-de-muertos',
  label: 'Día de Muertos',
  prefers: 'dark',            // solo aplica en modo Auto
  tokens: {
    accent:  '#FFB020',
    accent2: '#E0437F',
    tint:    '#1A0E2A',       // barra superior
    wash:    '#3B1A0A'        // velo de fondo
  },
  ambient: {
    strip:     { type: 'picado', colors: [...] },
    particles: { kind: 'petal', n: 14, colors: [...] },
    ornament:  'cempasuchil+calavera'
  },
  schedule: { from: '11-01', to: '11-30',
              blend: { 'halloween': [0.3, 0] } }
}

Resolución y aplicación

// theme-engine.js
weightsFor(date)   → { halloween: .72, 'dia-de-muertos': .28 }   // pesos normalizados
applyTheme(root, weights, { mode })
   ├─ mezcla los tokens por peso  → --t-accent, --t-accent2, --t-tint, --t-wash
   ├─ modo claro/oscuro           → el del tema dominante, salvo preferencia del usuario
   └─ monta capas ambientales     → cada tema con opacity = peso (crossfade sin cortes)

// Preferencia del usuario (localStorage 'sd_theme_pref')
'auto' | 'default' | '<id-de-tema>'      // Auto por defecto

// Integración con el index.html actual
:root { --brand-accent: var(--t-accent, #F5A623); }   // nuevo, solo para acentos de marca
// --ok / --warn / --crit / --info NO se reasignan nunca
<div id="ambientHost" aria-hidden="true"></div>   // capa con pointer-events:none, z-index:0
Reglas que mantienen la interfaz limpia
  • Los colores semánticos (verde correcto, ámbar advertencia, rojo crítico, azul informativo) nunca cambian con el tema: un tema no puede hacer que una advertencia parezca un acierto.
  • Los elementos ambientales viven en una capa con pointer-events:none, detrás del contenido, con opacidad máxima moderada y sin animaciones sobre tablas ni campos de captura.
  • Movimiento: 120 ms para respuestas inmediatas, 200 ms para entradas y salidas, 320 ms para cambios de estado; prefers-reduced-motion apaga partículas y reduce las transiciones a un cambio instantáneo.
  • Todo contraste se valida por tema: el texto sobre el acento se elige automáticamente (claro u oscuro) según su luminancia.
  • Un tema se puede desactivar con una línea en el registro, sin tocar el resto.
